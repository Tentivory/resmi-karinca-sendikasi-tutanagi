# T.C. Karınca Sendikası Genel Kurulu — Resmi Tutanak Üreticisi

> **UYARI:** Bu yazılım bir oyuncak değildir. Bu yazılım bir ulusal güvenlik meselesidir. Kırıntıların adil dağıtımı medeniyetin temelidir.

## Nedir Bu?

`resmi-karinca-sendikasi-tutanagi`, Türkiye Cumhuriyeti sınırları içinde (ve tezgah altında) faaliyet gösteren karınca işçi örgütlerinin genel kurul toplantılarını **resmi tutanak** formatında belgelemek üzere geliştirilmiş, bilimsel temeli tartışmalı, idari temeli çelik gibi bir araçtır.

İnsanlık yüzyıllardır karıncaların ne konuştuğunu merak etmiştir. Artık merak etmeye gerek yok. Bu program konuşmaları uydurur ve resmi damga basar. Uydurma ile gerçek arasındaki fark, damganın büyüklüğüdür.

## Neden Var?

Çünkü:

1. Kırıntı güvenliği milli meseledir.
2. Toplantı tutanağı olmayan karar geçersizdir.
3. Geçersiz kararlar yağmurda erir.
4. Yağmurda eriyen kararlar karıncaları üzar.
5. Üzgün karınca, yavaş karıncadır.
6. Yavaş karınca geç kalır.
7. Geç kalan karınca tutanağa giremez.

Bu yedi madde Anayasa'da yoktur ama bu depoda vardır. Yeter.

## Kurulum

```bash
git clone https://github.com/Tentivory/resmi-karinca-sendikasi-tutanagi.git
cd resmi-karinca-sendikasi-tutanagi
python3 tutanak.py
```

Bağımlılık yoktur. Sadece Python 3 ve biraz sabır. Sabır yoksa program zaten sizin yerinize bekler.

## Kullanım

Programı çalıştırın. Ekrana resmi bir tutanak dökülür. Yazıcınız varsa çıktıyı alıp buzdolabına asabilirsiniz. Buzdolabına asılan tutanaklar yüzde 40 daha resmi kabul edilir (kaynak: yok).

## Bilimsel Dayanak

- Karınca antenleri elektriksel sinyal taşır.
- Elektriksel sinyal tutanağa dönüşebilir.
- Dönüşüm sırasında anlam kaybı olur.
- Anlam kaybı mizahı doğurur.
- Mizah, damga ile resmiyet kazanır.

Bu zincir kırılırsa medeniyet çöker. Lütfen zinciri kırmayın.
